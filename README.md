# EV Market Analysis Dashboard

An Electric Vehicle (EV) Market Analysis project developed using Tableau Public to explore electric vehicle population data through interactive visualizations.

## Project Overview

This project analyzes electric vehicle data to understand vehicle distribution, leading manufacturers, model-year patterns, and geographic distribution. The dashboard presents the data in a visual format to support exploration and comparison.

## Objectives

- Analyze the distribution of Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Identify leading EV manufacturers by registered vehicle count.
- Explore vehicle distribution across model years.
- Examine geographic distribution across counties.
- Present key observations through an interactive Tableau dashboard.

## Tools and Technologies

- **Tableau Public:** Data visualization and dashboard development
- **Dataset:** Electric Vehicle Population Data
- **GitHub:** Project versioning and sharing

## Dashboard Visualizations

The dashboard includes:

1. Top 10 EV Manufacturers by Registered Vehicles
2. Vehicle Distribution by Type
3. EV Registrations by Model Year
4. EV Registrations by Geographic Area

## Project Files

- `EV_Market_Analysis_Dashboard_Final.twbx` — Packaged Tableau workbook.

## How to Open the Project

1. Download the `.twbx` workbook from this repository.
2. Install Tableau Public or a compatible version of Tableau Desktop.
3. Open the downloaded workbook in Tableau.
4. Review the dashboard and interact with the available visualizations and filters.

**Note:** Data availability and dashboard behavior may depend on how the workbook's data source is packaged.
